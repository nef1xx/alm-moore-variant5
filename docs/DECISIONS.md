# Принятые решения

Этот файл фиксирует недостающие в задании соглашения и позволяет продолжить работу без истории чата.

| Вопрос | Решение | Основание и последствия |
|---|---|---|
| Тип автомата | Мура | Прямо указан вариант 5 |
| Символ ^ перед X | НЕ | Прочтение исходных формул; XOR отсутствует |
| Переход в ЛСА | При A=1 по ↑ | Явно подтверждено пользователем |
| Что обозначает A | Проверка целиком | A2=¬F2, а не F2; A4=A5=¬F1 |
| Время | Один переход состояния на фронт CLK | Синхронная реализация управляющего автомата |
| Изменение входов | Между тактами | Позволяет моделировать ожидание и выход из циклов |
| Несколько проверок на пути | Один снимок F | Комбинационная часть одного перехода |
| Выходы | Полная маска состояния | Не перечисленные Y равны нулю |
| Завершение | S6 удерживается до RESET | Буквальная реализация «Конец» без автоматического нового запуска |
| Учебная альтернатива | Начало и конец S0 | Дополнительные ГСА/граф по соглашению из примера и учебной литературы |
| Элементы памяти | 3 синхронных RS-триггера | Тип RS выбран по присланному примеру; обязательной методички нет |
| Сброс | Синхронный, активная 1 | Учтён в функциях возбуждения и тестах |
| Неиспользуемый код | 111→000 за такт, Y=00000 | Полностью определённое восстановление |
| Область F при синтезе | Все 8 наборов | Недостижимые сочетания не используются как don't care |
| Минимальность F | Минимальная ДНФ по числу членов, затем литералов | Подтверждена точным перебором |
| Формат схем | SVG и PNG, именованные цепи | Редактирование и независимое чтение соединений |
| Формат программы | Python со стандартной библиотекой | Прямая просьба пользователя |

Граф с S6 и циклический граф не взаимозаменяемы после момента завершения. При переходе на циклическое оформление нужно последовательно применить изменения из раздела 8.7, а не просто стереть S6 на рисунке.
