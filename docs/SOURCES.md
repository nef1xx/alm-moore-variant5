# Источники и происхождение данных

Исходный 13-пунктный алгоритм и три функции F получены от пользователя и полностью приведены в [этапе 1](01_source.md). Обозначение условий A, операторов B и правило перехода при A=1 уточнены пользователем по разбору на занятии. Присланная работа другого варианта использовалась как ориентир структуры, а её решения не переносились в вариант 5.

Для проверки терминологии и различия соглашений использованы первичные учебные источники:

1. И. В. Жукалина. **Теория автоматов. Методические указания к курсовой работе для специальности 230101.** Оренбургский государственный университет, 2009. Разделы 3.1.1–3.2: разметка, графы, таблицы и структурный синтез. В источнике явно принято возвращение в начальное состояние после окончания микропрограммы. [PDF ОГУ](https://elib.osu.ru/bitstream/123456789/8908/1/1825_20110825.pdf).
2. Jonathan Valvano. **Chapter 4: Finite State Machines.** Учебный материал University of Texas at Austin: выходы автомата Мура определяются текущим состоянием, следующее состояние — входами и текущим состоянием. [Глава учебника](https://users.ece.utexas.edu/~valvano/mspm0/ebook/Ch4_FiniteStateMachines.html).

Эти источники служат для общих принципов, а не для подстановки решения варианта. Все таблицы истинности, минимальные функции, графы, условия переходов, функции возбуждения и проверки данного проекта вычислены по пользовательскому заданию. Использованное здесь правило ЛСА зафиксировано отдельно, потому что в литературе встречается и соглашение о переходе по стрелке при ложном условии.
