# 5 Построение графов автомата Мура

Из каждой отмеченной вершины ГСА прослежены пути до следующей отмеченной вершины. Проверки на одном пути объединены операцией И; альтернативные пути к одному состоянию — операцией ИЛИ. Выходы записаны внутри вершин, условия — на дугах.

Условия ниже относятся к RESET=0. Синхронный RESET=1 имеет приоритет и на следующем фронте переводит автомат в S0.

![Основной граф Мура](../diagrams/05_moore_graph.png)

## Вывод переходов

Из S0 условие F2=1 возвращает к проверке, поэтому возникает петля. При F2=0 исполняется B1 и автомат входит в S1. После B1 следующий оператор B2, следовательно S1→S2 безусловно.

Из S2 выполняется разбор пунктов 5–8:

- F2=0 ведёт к B3, то есть S3;
- F2=1, F3=1 ведёт к B4, то есть S4;
- F2=1, F3=0, F1=1 также ведёт к B4 через пункт 8;
- F2=1, F3=0, F1=0 ведёт к B5, то есть S5.

Два пути к S4 объединяются:

$$F_2F_3\vee F_2\overline{F_3}F_1=F_2(F_3\vee F_1).$$

Из S3 следующим оператором является B4, из S4 — B5. Из S5 сначала проверяется пункт 12. При F1=1 достигается конец S6. При F1=0 управление возвращается к пункту 5, а затем выбирается один из S3, S4, S5. Условия этого выбора относятся к тому же снимку F текущего такта.

| Откуда | Куда | Условие |
|---|---|---|
| S0 | S0 | F2 |
| S0 | S1 | ¬F2 |
| S1 | S2 | 1 |
| S2 | S3 | ¬F2 |
| S2 | S4 | F2(F3∨F1) |
| S2 | S5 | F2¬F3¬F1 |
| S3 | S4 | 1 |
| S4 | S5 | 1 |
| S5 | S3 | ¬F1¬F2 |
| S5 | S4 | ¬F1F2F3 |
| S5 | S5 | ¬F1F2¬F3 |
| S5 | S6 | F1 |
| S6 | S6 | 1 |

Для каждой исходной вершины условия полны и попарно несовместимы. Например, для S5 их сумма равна F1∨¬F1(¬F2∨F2F3∨F2¬F3)=1.

## Достижимые входы F(X)

Проверка 16 наборов X даёт только сочетания `001`, `010`, `101`, `111` в порядке F1F2F3. Поэтому:

- формальная дуга S5→S4 с условием ¬F1F2F3 недостижима при вычислении F из X;
- путь через пункт 8 требует F1=1 и F3=0, что невозможно для заданных функций на одном снимке X;
- дуга S2→S4 остаётся достижимой через F3=1 при F=111;
- все семь состояний остаются достижимыми при изменяющихся X.

![Граф с учётом достижимых сочетаний](../diagrams/05b_moore_reachable.png)

Этот рисунок является ограничением основного графа на реальную область входов. Основной граф и схема сохраняют корректное поведение на всех восьми формальных наборах F; недостижимые сочетания не использованы как неопределённости при синтезе.
