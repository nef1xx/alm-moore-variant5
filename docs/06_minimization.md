## Функция F1

![Карта Карно F1](../diagrams/06a_kmap_F1.png)

Получены четыре группы по четыре клетки:

| Группа | Минтермы | Сокращённая конъюнкция |
|---|---|---|
| G1 | 0,1,2,3 | ¬X1¬X2 |
| G2 | 10,11,14,15 | X1X3 |
| G3 | 4,5,12,13 | X2¬X3 |
| G4 | 4,6,12,14 | X2¬X4 |

G4 проходит через левый и правый края карты. Две части фиолетовой рамки составляют одну группу из четырёх клеток. В каждой группе меняются две переменные, поэтому после сокращения остаются два литерала.

$$\boxed{F_1=\overline{X_1}\overline{X_2}\vee X_1X_3\vee X_2\overline{X_3}\vee X_2\overline{X_4}}$$

Нулевые минтермы F1 — только 7,8,9. Все остальные клетки покрыты, нули не включены ни в одну группу.

## Функция F2

![Карта Карно F2](../diagrams/06b_kmap_F2.png)

G1 объединяет 8 клеток с X2=0. Это первая и последняя строки, которые соседствуют через край. G2 объединяет 4 клетки с X1=1 и X3=0.

Алгебраическая проверка результата:

$$\overline{X_2}X_3\vee\overline{X_2}\overline{X_3}=\overline{X_2}.$$

Член ¬X1¬X2 поглощается ¬X2. Затем по правилу a∨¬ab=a∨b:

$$\overline{X_2}\vee X_1X_2\overline{X_3}=\overline{X_2}\vee X_1\overline{X_3}.$$

$$\boxed{F_2=\overline{X_2}\vee X_1\overline{X_3}}$$

## Функция F3

![Карта Карно F3](../diagrams/06c_kmap_F3.png)

Три группы по восемь клеток соответствуют ¬X1, X2 и X3. При X1=0 исходная функция всегда равна 1: при X3=0 срабатывает ¬X1¬X3, при X3=1 срабатывает X2X3 либо ¬X1¬X2X3. При X1=1 функция равна X3∨X2. Следовательно:

$$F_3=\overline{X_1}\vee X_1(X_2\vee X_3)=\overline{X_1}\vee X_2\vee X_3.$$

$$\boxed{F_3=\overline{X_1}\vee X_2\vee X_3}$$

## Как подтверждена минимальность

Эквивалентность сама по себе не доказывает минимум. Поэтому программа отдельно перебирает все 3⁴ кубов из символов 0,1,«неважно», оставляет допустимые импликанты, выделяет простые импликанты и перебирает их покрытия единичного множества. Сначала минимизируется количество конъюнкций, затем количество литералов.

| Функция | Минимум конъюнкций | Минимум литералов при этом количестве |
|---|---:|---:|
| F1 | 4 | 8 |
| F2 | 2 | 3 |
| F3 | 3 | 3 |

Для F1 существует шесть равноценных минимальных ДНФ. Все они, простые импликанты и покрываемые минтермы приведены в [сертификате минимизации](../data/minimization.json). Минимальность относится к ДНФ в указанном критерии; стоимость произвольной многоуровневой схемы отдельно не оптимизировалась.
