# 2 Построение блок-схемы

Из каждого пункта списка был построен соответствующий узел: начало/конец, операторный прямоугольник или условный ромб. Пункт 8 представлен направленной линией с подписью, поскольку это безусловный переход без выходного действия.

Для каждого условия отдельно проверены обе ветви. На схеме 1 означает истинность проверки целиком, 0 — её ложность. Например, у ромба «F2=0» ветвь 1 соответствует нулевому значению F2.

![Блок-схема исходного алгоритма](../diagrams/01_flowchart.png)

## Обозначения для перехода к ЛСА

| Метка | Пункт | Содержание |
|---|---:|---|
| A1 | 2 | F2=1 |
| A2 | 5 | F2=0 |
| A3 | 6 | F3=1 |
| A4 | 7 | F1=0 |
| A5 | 12 | F1=0 |
| B1 | 3 | Y1,Y3,Y5 |
| B2 | 4 | Y2,Y4 |
| B3 | 9 | Y1,Y4 |
| B4 | 10 | Y1,Y5 |
| B5 | 11 | Y2,Y3,Y5 |

Одинаковые проверки в разных местах алгоритма имеют разные метки. A1 и A2 используют один сигнал F2, но противоположные условия. A4 и A5 имеют одинаковую формулу, но разные позиции и последующие переходы.

![Блок-схема с обозначениями A и B](../diagrams/02_flowchart_labeled.png)

Проверка схемы выполнялась по исходным адресам переходов, особенно 2→2, 8→10 и 12→5. Метки A/B пока обозначают элементы алгоритма; состояния автомата назначаются на этапе 4.
