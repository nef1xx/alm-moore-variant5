# 11 Публикация и доступ к проекту

Проект загружен в [nef1xx/alm-moore-variant5](https://github.com/nef1xx/alm-moore-variant5), основная ветка — `main`. Репозиторий приватный: материалы доступны при входе в аккаунт владельца или при отдельно выданном доступе. Автор коммитов — `nef1xx`, адрес автора — GitHub noreply.

В репозиторий включены пояснения всех этапов, 19 схем в SVG и PNG, PDF-альбом из 20 страниц, CSV/JSON, исходный код, генераторы и тесты. Чужой DOCX-пример, временные файлы и данные авторизации не включены.

После загрузки выполнено клонирование с GitHub в отдельную папку. В этой копии успешно выполнены все 12 тестов, демонстрация, пересборка данных и галереи. Пересборка не изменила отслеживаемые файлы. Также успешно завершилась [проверка GitHub Actions первого коммита](https://github.com/nef1xx/alm-moore-variant5/actions/runs/34058284945): Python 3.12 на Ubuntu, unittest, пересборка данных и проверка отсутствия расхождений.

## Как забрать материалы

Для просмотра откройте README и выберите этап или [галерею схем](SCHEMES.md). Для скачивания всего проекта используйте в GitHub **Code → Download ZIP** либо:

```bash
gh repo clone nef1xx/alm-moore-variant5
cd alm-moore-variant5
python -m ulu.cli --demo
python -m unittest discover -s tests -v
```

Команда `gh` требует входа в аккаунт с доступом к приватному репозиторию. Для запуска скачанной программы достаточно Python 3.10 или новее.

## Передача другому агенту

Предоставьте агенту доступ к папке проекта либо репозиторию. Начальные файлы: [README](../README.md), [AGENTS.md](../AGENTS.md), [принятые решения](DECISIONS.md). Они содержат исходное задание, трактовку ЛСА, различие основного и циклического автоматов, структуру проекта и команды проверки. Содержимое чата не требуется.
