# 7 Схема формирования входных сигналов F

Минимизированные выражения переведены в базис И, ИЛИ, НЕ. Каждой конъюнкции соответствует вентиль И; объединению конъюнкций — ИЛИ. Отрицания общие для всех потребителей.

![Схема формирования F](../diagrams/07_input_logic.png)

На схемах используются именованные цепи. Одинаковая подпись означает электрическое соединение соответствующих выводов. Например, выход `p11` подключён ко входу `p11` элемента F1. Это позволяет показать соединения без неоднозначных пересечений длинных проводов.

## Порядок сборки

1. Сформировать nX1=¬X1, nX2=¬X2, nX3=¬X3, nX4=¬X4 четырьмя инверторами.
2. Для F1 сформировать p11=nX1·nX2, p12=X1·X3, p13=X2·nX3, p14=X2·nX4. Объединить четыре результата элементом ИЛИ.
3. Для F2 сформировать p21=X1·nX3. Подать p21 и nX2 на ИЛИ.
4. Для F3 подать nX1, X2, X3 на трёхвходовый ИЛИ.

Если многовходовые элементы недоступны, И и ИЛИ с тремя или четырьмя входами можно разложить в каскады двухвходовых элементов. Логическая функция при этом сохраняется.

При учёте каждого многовходового вентиля как одного элемента входной узел содержит 4 НЕ, 5 И, 3 ИЛИ. Выход F3 не зависит от X4, как и F2. Потребность в ¬F1,¬F2,¬F3 относится уже к следующему узлу управляющего автомата и показана на листе 08c.

Схема построена из тех же записей вентилей, которые вычисляет Python-модель. Все 16 входных наборов проверяются против исходных, ещё не минимизированных выражений.
