# 7 Схема формирования входных сигналов F

Минимизированные выражения переведены в базис И, ИЛИ, НЕ. Каждой конъюнкции соответствует вентиль И; объединению конъюнкций — ИЛИ. Отрицания общие для всех потребителей.

![Схема формирования F](../diagrams/07_input_logic.png)

На этом листе показана **полная схема соединений от X1–X4 до F1–F3**. Все входы элементов соединены проводами. Вертикальные линии — отдельные цепи прямых и инвертированных X; разветвление с электрическим соединением отмечено закрашенной точкой. Пересечение проводов без точки не является соединением. Пустой кружок на выходе элемента обозначает инверсию.

Имена `p11`–`p21` поясняют промежуточные результаты; их соединения с ИЛИ видны непосредственно на рисунке. Выходы F1–F3 подключаются к одноимённым входам логики переходов [листа 08c](../diagrams/08c_transition_logic.png), как показано на [структурной схеме УЛУ](../diagrams/08a_hardware_overview.png). На детальных листах этапа 8 соединение между отдельными элементами и листами по-прежнему обозначается одинаковыми именами цепей.

## Обозначения элементов

Использованы прямоугольные обозначения по присланному образцу: `&` для И, `1` для ИЛИ, `1` с одним входом и пустым кружком на выходе для НЕ.

| Функция | Операция | Обозначение |
|---|---|---|
| X1·X2 | И | `&`, два входа |
| ¬(X1·X2) | И-НЕ | `&` с кружком на выходе |
| X1∨X2 | ИЛИ | `1`, два входа |
| ¬(X1∨X2) | ИЛИ-НЕ | `1` с кружком на выходе, два входа |
| X1⊕X2 | Исключающее ИЛИ | `=1` (в эскизе — `=`), два входа |
| ¬(X1⊕X2) | Исключающее ИЛИ-НЕ | `=1` с кружком на выходе |
| ¬X1 | НЕ | `1`, один вход, кружок на выходе |

**¬X1·¬X2 и ¬(X1·X2) — разные функции.** Например, при X1=0, X2=1 первая равна 0, а вторая — 1. Поэтому для первого слагаемого F1 оба X инвертируются перед входами И. Кружок только на выходе И дал бы другое выражение. В исходных формулах `^X` означает отрицание следующей переменной; XOR в данном варианте отсутствует.

## Реализуемые минимизированные функции

$$F_1=\overline{X_1}\overline{X_2}\vee X_1X_3\vee X_2\overline{X_3}\vee X_2\overline{X_4}$$

$$F_2=\overline{X_2}\vee X_1\overline{X_3}$$

$$F_3=\overline{X_1}\vee X_2\vee X_3$$

## Порядок сборки

1. Сформировать nX1=¬X1, nX2=¬X2, nX3=¬X3, nX4=¬X4 четырьмя инверторами.
2. Для F1 сформировать p11=nX1·nX2, p12=X1·X3, p13=X2·nX3, p14=X2·nX4. Объединить четыре результата элементом ИЛИ.
3. Для F2 сформировать p21=X1·nX3. Подать p21 и nX2 на ИЛИ.
4. Для F3 подать nX1, X2, X3 на трёхвходовый ИЛИ.

Если многовходовые элементы недоступны, И и ИЛИ с тремя или четырьмя входами можно разложить в каскады двухвходовых элементов. Логическая функция при этом сохраняется.

При учёте каждого многовходового вентиля как одного элемента входной узел содержит 4 НЕ, 5 И, 3 ИЛИ. Выход F3 не зависит от X4, как и F2. Потребность в ¬F1,¬F2,¬F3 относится уже к следующему узлу управляющего автомата и показана на листе 08c.

Схема построена из тех же записей вентилей, которые вычисляет Python-модель: из них берутся типы элементов и источники всех входных проводов. Генератор проверяет наличие всех входных соединений и отсутствие проводов, проходящих сквозь корпуса элементов. Все 16 входных наборов проверяются против исходных, ещё не минимизированных выражений.
