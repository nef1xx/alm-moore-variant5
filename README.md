# Итоговая работа по АЛМ — вариант 5 — автомат Мура

Проект содержит полный разбор устройства логического управления: исходный алгоритм, блок-схему, ЛСА, отмеченную ГСА, графы Мура, минимизацию входных функций, схему на логических элементах и RS-триггерах, а также её проверяемую модель на Python.

**Начните с таблицы этапов ниже. Все изображения, исходники и результаты находятся в репозитории; история чата для их понимания не требуется.** Для другого агента подготовлен [AGENTS.md](AGENTS.md), а принятые допущения вынесены в [DECISIONS.md](docs/DECISIONS.md).

Основная реализация имеет **7 состояний и 3 триггера**. В состоянии `S6` алгоритм завершён, все `Y` равны нулю; повторный запуск происходит после синхронного сброса. Дополнительно дан учебный циклический граф с 6 состояниями и общим состоянием начала/конца `S0`. Это различие разобрано в этапе 4. **Аппаратные формулы и класс Hardware относятся к основному графу с S6.**

## Полученные минимальные функции

$$F_1=\overline{X_1}\overline{X_2}\vee X_1X_3\vee X_2\overline{X_3}\vee X_2\overline{X_4}$$

$$F_2=\overline{X_2}\vee X_1\overline{X_3}$$

$$F_3=\overline{X_1}\vee X_2\vee X_3$$

Эквивалентность исходным выражениям проверена на всех 16 наборах `X1X2X3X4`. Минимальность ДНФ подтверждена полным перебором простых импликант и их покрытий. Для `F1` есть несколько равноценных минимальных ДНФ; выбранная выше имеет 4 конъюнкции и 8 литералов.

## Запуск за минуту

Нужен Python 3.10 или новее. Модель и тесты используют только стандартную библиотеку.

```bash
python -m ulu.cli --demo
python -m ulu.cli --interactive
python -m unittest discover -s tests -v
```

В Windows также можно использовать `py` вместо `python`. В интерактивном режиме вводите четыре бита `X1X2X3X4`, `r` для такта со сбросом или `q` для выхода. Входы разрешено менять на каждом такте. `--model hardware` используется по умолчанию: вычисляются вентили, входы S/R и новое состояние триггеров.

```bash
python -m ulu.cli --sequence 0100,0100,1010,1000,1000,0111,0100,1010,0100 --csv trace.csv
python -m ulu.cli --model behavior --cyclic --demo
```

## Проверка результата

Есть независимый интерпретатор исходного списка команд, интерпретатор ЛСА, поведенческий автомат и модель списка вентилей. Проверяются все формальные наборы `F`, все реальные наборы `X`, выходы, недопустимый код, сброс и длинные меняющиеся последовательности. Запрещённое сочетание `S=R=1` исключено уравнениями и проверками.

Python моделирует синхронную цифровую схему. Физическая плата и задержки конкретных микросхем в проект не входят. Схема дана на уровне вентилей и триггеров, достаточном для канонического структурного синтеза и переноса в схемный редактор.

Источники теории перечислены в [SOURCES.md](docs/SOURCES.md). Разбор выполненного процесса — в [WORKLOG.md](docs/WORKLOG.md).
